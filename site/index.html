Resolve ambiguous bases in your ONT consensus, in the browser.

DeGenRESOLVE turns raw fastq_pass reads and a reference into refined consensus FASTA files. It decides every IUPAC ambiguity code from the read pileup and writes detailed QC reports. This page starts the real desktop app in your own GitHub Codespace, with nothing to install.

How it works

The same release, the same tool versions, and the same results as a local install.

  1. Start a codespace

    GitHub creates a private 4-core, 16 GB machine under your account. It has DeGenRESOLVE and every tool it needs, at the exact versions the published results were made with. Startup takes a few minutes.

  2. Use the desktop app

    The DeGenRESOLVE window opens in a browser tab. Run the bundled influenza A demo (5–7 minutes), or drag your own run folder in and press Start.

  3. Download your results

    You get a consensus FASTA per barcode, a 27-column diagnostic log, and HTML QC reports. One command zips them for download.

Who pays

You do, from GitHub's free allowance, and nothing is billed to the authors. GitHub Free includes 120 Codespaces core-hours a month. That's about 30 hours on this 4-core machine.

A codespace stops after 30 minutes without activity. You can stop or delete it any time at github.com/codespaces.

Where your data goes

Reads you upload stay inside your own codespace, a private machine under your GitHub account. Nothing is sent to the DeGenRESOLVE authors.

Only upload data you're permitted to process on a cloud service. Delete the codespace once you've downloaded your results.

What to upload

Drag one run folder into my_data/ in the codespace. It needs this layout:

your_run/
├── fastq_pass/
│   ├── barcode01/  # *.fastq.gz
│   ├── barcode02/
│   └── …
└── reference/
    └── panel.fasta # exactly one
  • Reads must be gzip-compressed FASTQ (.fastq.gz). Each barcode folder name starts with barcode.
  • Put every segment of a segmented virus, such as influenza, in the one reference file. Choose Influenza filter mode in Configuration.
  • The basecall tier (hac / sup / fast) is read from the reads and recorded in each run receipt.

Prefer your own computer?

DeGenRESOLVE runs offline on Linux, or on Windows through WSL 2. The offline bundle needs no internet on the target machine and no preinstalled bioinformatics tools.
